# Дефекты

Реестр дефектов SoundShare: найденных при верификации требований, сверке требований с реализацией и выполнении тест-кейсов.

**Важность:** критическая — не работает ключевой сценарий, потеря данных, уязвимость; значительная — функция работает неверно, обхода нет; умеренная — есть обходной путь; незначительная — косметика.
**Срочность:** высокая — исправить до следующего цикла тестирования; средняя — до завершения вехи; низкая — при возможности.

### DEF-007. Описанный в ТЗ `MERGE` снятия голоса нарушает ограничение

| Поле | Значение |
|---|---|
| Требование | BR-VOTE-03 |
| Ожидаемый результат | `MERGE … WHEN MATCHED THEN UPDATE … DELETE WHERE` со значением 0 удаляет голос |
| Фактический результат | `ORA-02290: check constraint (SOUNDSHARE.CK_TRACK_VOTES_VALUE) violated`: Oracle выполняет `UPDATE` значением 0 и проверяет `CHECK` до `DELETE WHERE` |
| Шаги воспроизведения | 1. Применить миграции. 2. Вставить голос +1. 3. Выполнить `MERGE … UPDATE SET vote_value = 0 DELETE WHERE 0 = 0` |
| Воспроизводимость | Всегда |
| Важность / срочность | Значительная / высокая: снятие голоса невозможно |
| Симптом | Ошибка БД при снятии голоса |
| Возможность обойти | Да — отдельный `DELETE` |
| Исправление | BR-VOTE-03 уточнено: при снятии `UPDATE` сохраняет прежнее значение; регрессионный тест в `db/tests/constraints_test.sql` («naive MERGE writes 0 before DELETE WHERE») |

### DEF-008. Тест-кейсы с неоднозначным ожидаемым результатом

| Требование | Задание 3: ожидаемый результат тест-кейса; TC-09, TC-17, TC-22, TC-36, TC-37, TC-38 |
| Ожидаемый результат | Каждый шаг имеет один ожидаемый результат, по которому однозначно определяется статус «Пройден» или «Провален» |
| Фактический результат | Ожидаемые результаты содержали варианты: «`401` или `403`», «`409` или `422`», «`403` или `404`», «`500` или `503`», «вход успешен либо `404`»; адреса API не были зафиксированы |
| Шаги воспроизведения | 1. Найти в test-cases.md ожидаемые результаты со словами «или», «либо» |
| Воспроизводимость | Всегда |
| Важность / срочность | Умеренная / высокая: при выполнении статус тест-кейса зависел бы от трактовки |
| Симптом | Неоднозначный критерий прохождения |
| Возможность обойти | Нет |
| Исправление | Зафиксирован [контракт API](docs/api/endpoints.md) (адреса, тела, коды ответов); тест-кейсы приведены к нему |
