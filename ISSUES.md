# Дефекты

Реестр дефектов SoundShare: найденных при верификации требований, сверке требований с реализацией и выполнении тест-кейсов.

Шкалы и поля отчёта о дефекте — по пособию Куликова С. С. «Тестирование программного обеспечения. Базовый курс».

**Важность:** критическая — ключевой сценарий не работает, потеря данных, уязвимость; высокая — функция работает неверно, обхода нет; средняя — есть обходной путь; низкая — незначительный недостаток.
**Срочность:** наивысшая — исправить немедленно; высокая — до следующего цикла тестирования; обычная — в плановом порядке; низкая — при возможности.

### DEF-007. Описанный в ТЗ `MERGE` снятия голоса нарушает ограничение

| Поле | Значение |
|---|---|
| Требование | BR-VOTE-03 |
| Ожидаемый результат | `MERGE … WHEN MATCHED THEN UPDATE … DELETE WHERE` со значением 0 удаляет голос |
| Фактический результат | `ORA-02290: check constraint (SOUNDSHARE.CK_TRACK_VOTES_VALUE) violated`: Oracle выполняет `UPDATE` значением 0 и проверяет `CHECK` до `DELETE WHERE` |
| Шаги воспроизведения | 1. Применить миграции. 2. Вставить голос +1. 3. Выполнить `MERGE … UPDATE SET vote_value = 0 DELETE WHERE 0 = 0` |
| Воспроизводимость | Всегда |
| Важность / срочность | Высокая / высокая: снятие голоса невозможно |
| Симптом | Некорректная операция |
| Возможность обойти | Да — отдельный `DELETE` |
| Исправление | BR-VOTE-03 уточнено: при снятии `UPDATE` сохраняет прежнее значение; регрессионный тест в `db/tests/constraints_test.sql` («naive MERGE writes 0 before DELETE WHERE») |

### DEF-009. Список публичных комнат возвращает 500

| Поле | Значение |
|---|---|
| Требование | FR-ROOM-01; TC-10 |
| Ожидаемый результат | `GET /api/rooms` возвращает `200` и список публичных активных комнат с числом участников |
| Фактический результат | `500 Internal Server Error`; в логе `InvalidCastException: Unable to cast Int32 to Boolean` в `OracleBoolTypeMapping.GenerateNonNullSqlLiteral` |
| Шаги воспроизведения | 1. Поднять БД с демо-данными. 2. Войти как `user_1`. 3. Выполнить `GET /api/rooms` |
| Воспроизводимость | Всегда |
| Важность / срочность | Критическая / наивысшая: ключевой сценарий «найти комнату» не работает |
| Симптом | Крах системы |
| Возможность обойти | Нет |
| Окружение | API commit 8dfbbaa, Oracle 23ai Free, демо-данные `db/seed/demo.sql` |
| Причина | Собственный конвертер `bool → 0/1` поверх `NUMBER(1)` конфликтовал со встроенным маппингом провайдера при генерации SQL-литерала `IS_ACTIVE = 1` |
| Исправление | Конвертер удалён, булевы свойства маппятся на `NUMBER(1)` штатно; запрос списка разделён на выборку комнат и сгруппированный подсчёт участников (commit eadb896) |
