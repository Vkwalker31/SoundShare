# Руководство пользователя SoundShare

SoundShare — веб-приложение для совместного прослушивания музыки: участники комнаты слушают одну очередь, добавляют треки и голосуют за них, а очередь перестраивается у всех в реальном времени.

## 1. Начало работы

### 1.1 Запуск (для администратора стенда)

1. Установите Docker Desktop и .NET SDK 10.
2. Скопируйте `.env.example` в `.env` и задайте пароли.
3. Поднимите БД и примените схему — см. раздел «Запуск» в [README](../README.md).
4. Запустите приложение:
   ```bash
   dotnet run --project src/SoundShare.WebApi
   ```
5. Откройте в браузере `http://localhost:5290`.

Демо-пользователи: `admin` (администратор), `user_owner`, `user_mod`, `user_1` … `user_7`; пароль у всех — `Demo_Pass1`.

### 1.2 Регистрация и вход

- **Регистрация**: на странице входа нажмите «Зарегистрироваться», укажите имя (3–32 символа: латинские буквы, цифры, `_`), email и пароль (не короче 8 символов, буквы и цифры).
- **Вход**: имя и пароль. Сессия сохраняется 7 дней: при повторном открытии браузера входить заново не нужно.
- **Выход**: кнопка «Выйти» в правом верхнем углу. Сессия завершается на сервере.
- После 5 неудачных попыток входа за минуту вход временно блокируется — подождите минуту.

## 2. Комнаты

### 2.1 Список комнат

На главной странице — публичные комнаты с числом участников онлайн. Нажмите «Войти», чтобы присоединиться.

Пользователь может находиться только в одной комнате: при входе в другую он автоматически выходит из предыдущей.

### 2.2 Создание комнаты

В блоке «Создать комнату» введите название (до 100 символов) и при необходимости отметьте «Приватная». Создатель становится **владельцем**. Приватная комната не показывается в списке — в неё входят по коду приглашения, который виден участникам в заголовке комнаты («код ABC234»).

### 2.3 Вход по коду

В блоке «Войти по коду» введите 6-символьный код (регистр не важен).

### 2.4 Роли в комнате

| Роль | Возможности |
|---|---|
| Участник | Добавлять треки (не больше 3 одновременно в очереди), голосовать, голосовать за пропуск, удалять свои треки |
| Модератор | Плюс: закреплять и откреплять треки, пропускать трек без голосования, удалять любые треки, исключать участников |
| Владелец | Плюс: назначать модераторов, передавать владение, закрывать комнату |

Если владелец выходит, владельцем становится модератор, а если модераторов нет — самый давний участник.

## 3. Очередь и воспроизведение

### 3.1 Плеер

Слева — текущий трек: обложка (или видео, если включить «Видео»), название, исполнитель и прогресс. Все участники слышат один и тот же момент трека: вошедший позже начинает с текущей позиции. Когда трек заканчивается, автоматически начинается следующий.

### 3.2 Добавление трека

В блоке «Добавить трек» найдите песню по названию или исполнителю и нажмите «Добавить». Если трека нет в каталоге, он ищется на YouTube; если YouTube недоступен, показываются только треки каталога (с пометкой). Добавленный трек сразу получает ваш голос «+1».

### 3.3 Порядок очереди

1. Закреплённые модератором треки — в порядке закрепления.
2. Остальные — по рейтингу (сумме голосов).
3. При равном рейтинге — кто раньше добавлен.

### 3.4 Голосование

Кнопки «+» и «−» рядом с треком. Повторное нажатие того же голоса ничего не меняет; можно передумать. Трек с рейтингом **−5** автоматически удаляется из очереди (кроме закреплённых).

### 3.5 Пропуск трека

Кнопка «Пропустить» под плеером — голос за пропуск. Трек пропускается, когда за это проголосовало больше половины участников онлайн; прогресс («3/5») виден всем. Модератор может нажать «Пропустить сейчас».

### 3.6 Если пропало соединение

Над комнатой появится «Нет соединения. Переподключаемся…». После восстановления сети очередь обновится автоматически, перезагружать страницу не нужно.

## 4. Администрирование

Пункты «Пользователи» и «Журнал» видны только администратору.

### 4.1 Пользователи

- Фильтры по роли и статусу, постраничный просмотр.
- «Сделать Admin / Сделать User» — смена роли. Снять роль с последнего администратора нельзя.
- «Заблокировать / Разблокировать». Заблокированный пользователь не может войти, его сессии завершаются сразу.

### 4.2 Журнал действий

Таблица всех изменяющих действий: время (UTC), источник (`HTTP` — запрос, `DOMAIN` — изменение в БД, `HUB` — real-time), пользователь, действие (`Queue.Vote`, неуспешное — `Queue.PinFailed`), запрос, код ответа и длительность. Фильтры по id пользователя и действию, кнопка «Ещё» загружает более старые записи. Неуспешные действия выделены цветом.

## 5. Удаление аккаунта

Запрос `DELETE /api/users/me` с паролем (в интерфейсе — через администратора). Имя и email заменяются обезличенными, вход становится невозможен; добавленные треки и голоса остаются в истории комнат.

## 6. Возможные проблемы

| Сообщение | Причина | Что делать |
|---|---|---|
| «Неверное имя пользователя или пароль» | Опечатка в имени или пароле | Проверить раскладку и Caps Lock |
| «Слишком много попыток, подождите минуту» | 5 неудачных входов за минуту | Подождать минуту |
| «You already have 3 tracks in the queue» | В очереди уже 3 ваших трека | Дождаться, пока один из них сыграет, или удалить свой трек |
| «Комната с таким кодом не найдена» | Неверный код или комната закрыта | Уточнить код у участников |
| «You are banned from this room until …» | Модератор исключил вас | Дождаться окончания бана |
| «Поиск на YouTube сейчас недоступен» | Нет ключа или исчерпана квота YouTube API | Искать по каталогу |
| Страница «Комната недоступна» | Комната закрыта или вас исключили | Вернуться к списку комнат |
