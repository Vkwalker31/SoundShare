# Чек-лист функциональных проверок

Покрывает все функциональные требования (FR) и бизнес-правила (BR) [технического задания](../01-technical-specification.md). Проверки сгруппированы по модулям приложения; у каждого требования есть позитивная (**П**) и негативная (**Н**) проверка. Колонка «ТК» ссылается на [тест-кейсы](test-cases.md); «авто» — проверка выполняется автотестом.
