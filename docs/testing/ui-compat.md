# Вёрстка, адаптивность и кроссбраузерность (задание 4)

Проверка выполнена автоматически тестом `CompatibilityTests` (Playwright) и просмотром скриншотов; дата — 20.10.2026. Сборка `main`, демо-данные пересозданы перед прогоном.

## 1. Браузеры и устройства

| Браузер | Сборка | Режим |
|---|---|---|
| Google Chrome | установленный Chrome (канал `chrome`) | Десктоп; на 360 px — эмуляция мобильного устройства (`IsMobile`, сенсорный ввод) |
| Microsoft Edge | установленный Edge (канал `msedge`) | То же |
| Mozilla Firefox | Firefox 153 (сборка Playwright) | Десктоп; на 360 px — только ширина окна (Firefox не поддерживает эмуляцию мобильного устройства) |

Масштаб страницы моделируется шириной окна: 2560 px при экране 1280 px ≈ 50 %, 640 px ≈ 200 %.

## 2. Что проверялось на каждой странице и ширине

1. **Целостность блоков и сетка** — нет горизонтальной прокрутки (`scrollWidth − clientWidth = 0`), карточки не накладываются; на ширине ≤ 820 px колонки комнаты выстраиваются в одну.
2. **Реальные данные** — очередь из нескольких позиций (Rock & Metal Bar), пустая очередь и пустой плеер, название комнаты из 60 одинаковых широких букв без пробелов (перенос по `overflow-wrap: anywhere`), длинные имена пользователей, таблицы администрирования с прокруткой внутри блока, страница 404.
3. **Ошибки** — нет сообщений об ошибках в консоли и ответов 4xx/5xx на запросы страницы.
4. **Интерактивные элементы** — favicon, переход по логотипу, видимый фокус, реакция на наведение, заголовки вкладок.
